# Notebook Descriptions

**Notebook Map Overview** -> The notebooks and their specific functions and purposes in this technical note will be listed in this section of the README. Additional information on how to run these notebooks is provided in the next section.

01_baseline_strength_model.ipynb is used as a baseline notebook for exploratory data analysis (EDA) using the baseline dataset. Its initial untuned models analyze feature importance, target distribution, and feature correlation. This notebook also has a train-test split and cross-validation to evaluate the accuracy of the machine learning models.

02_cv_tuning_and_outputs.ipynb acts as the final baseline modeling notebook and should be referred to for the final baseline results. Unlike 01_baseline_strength_model.ipynb, this notebook utilizes hyperparameter tuning on the training set (from an 80-20 train-test split or group shuffle split + cross-validation) to create the best model. It also saves the final figures and the CSV outputs for publication usage. This notebook also has Pareto exploration, utilizing cost and sustainability proxies from relevant literature to create publishable figures. The Pareto exploration should be considered a proxy analysis, as geographical and temporal differences within the data prevent it from being classified as a full LCA.

03_rca_dataset_modeling.ipynb is an RCA extension of the present technical note, utilizing an RCA-specific dataset that contains recycled aggregates rather than SCMs with a similar process to 02_cv_tuning_and_outputs.ipynb. Data preprocessing in this notebook uses manual review to deal with erroneous data, alongside removing duplicates to avoid disproportionate statistical weighting within the smaller RCA dataset. Additionally, the notebook implements repeated nested grouped cross-validation to evaluate model robustness across multiple grouped splits. Afterwards, a total of 30 splits are run through repeated nested grouped cross-validation to evaluate the robustness of the entire modeling procedure. Subsequently, nested group-aware out-of-fold predictions are generated for every cleaned observation within each outer fold. This process uses its own training data to select new feature sets and model configurations, similar to the repeated nested grouped cross-validation process. These predictions are used for the Pareto analysis so that each row is predicted by a model that was not trained on that row's mixture group. Pareto exploration should be treated the same as in 02_cv_tuning_and_outputs.ipynb.
